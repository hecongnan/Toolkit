# 任务笔记

## 启用

在 Supabase SQL Editor 执行完整 `lib/supabase/migrations/20261016_task_notes.sql`。前提是现有任务表及重复任务迁移已经安装；全新数据库按 README 中的顺序执行。已启用时间记录的旧库，本轮只需新增这一份迁移。

迁移创建 `task_notes`、索引、RLS、关联检查和 `note_save` / `note_list` / `note_delete` 三个 RPC。不删除或覆盖任务、时间记录或旧学习资料，支持重复运行。请先在测试项目验证、按自己的备份流程备份正式库，再升级。代码测试不等于正式迁移已执行。

无需新密钥、依赖或后台服务。EdgeOne 继续不使用 middleware；发布前先完成数据库升级。没有迁移时，笔记页显示更新提示，不影响任务完成和时间记录。

## 使用

- 完成每日任务仍是一次勾选。成功提示中的“记录笔记”是可选入口，不自动弹窗，不要求先写笔记才能完成。
- 未完成或已完成的任务均可写笔记；桌面操作按钮、手机任务菜单提供“写笔记”，任务行的“任务笔记”可查看这一项的全部笔记。
- 导航中的“笔记”显示全部笔记。新建时可独立记录，也可选择今日任务；从某次任务打开时带入该任务，无论它是否属于今天。
- 每篇笔记的标题可选，留空时使用正文第一行；标题最多120字，正文最多20000字。正文保存原始换行、代码缩进和空格，不执行 HTML，不提供富文本、Markdown 渲染、附件或公开分享。
- 默认显示简短正文预览，可展开全文。搜索覆盖所有已保存笔记，而非只搜当前页；空格分隔的关键词全部匹配，可跨标题、正文、记录时任务名。特殊字符按文字搜索，不作为查询表达式执行。每页最多50篇。
- 笔记可编辑或删除。删除会确认，不会删除关联任务或时间记录。版本冲突不会自动覆盖新内容，可保留输入并另存为新笔记，原笔记不变。

## 与任务的关系

`task_id` 关联某次任务，不关联整个重复系列。因此同名的每日重复任务各有自己的笔记；取消完成、改期、重新完成不创建或删除笔记。笔记本身没有独立“完成状态”。

保存关联时记录任务标题和日期快照，用来说明当时的背景。任务改名后仍能按旧名称找到这篇笔记；“返回关联任务”会读取该任务当前名称和日期再定位，避免改期后跳到错误日期。

删除任务后，外键把关联 ID 设为 null，笔记与原任务背景仍保留。主动在编辑器解除关联会清除该关联背景；已经因任务删除而保留的历史背景，普通正文编辑不会抹掉。笔记与任务只能属于同一账号。

## 草稿与失败保护

草稿以账号 ID 隔离，保存在当前标签页的 sessionStorage，一次保留一个编辑中的笔记，包括原笔记版本和关联任务。它不等于服务器保存，不跨设备，也不保证关闭标签页后恢复；浏览器会话恢复行为由浏览器决定。

重新打开编辑器时，如有草稿，会先询问是否恢复并显示其原关联，不把它悄悄改绑到新点击的任务。修改内容再还原到原值时，清除本编辑器留下的旧草稿，避免恢复已撤销的输入。

关闭有修改的笔记时可继续编辑、保留草稿后关闭，或明确放弃。刷新/离开页面同时触发浏览器的未保存提示，但浏览器可能限制该提示，所以不能只依赖提示。存储失败时明确警告、禁用“保留草稿并关闭”，仍可继续输入和提交到服务器；清理草稿失败时不声称清理成功。

创建笔记使用稳定 ID，网络响应丢失后重试不会生成第二篇。若服务端已有同 ID、但内容不同，不把新输入静默当作保存成功。编辑、删除使用版本号检测旧页面操作；保存期间锁定重复提交和关闭，失败保留当前输入。

## 数据与维护边界

RLS 限制账号读写自己的笔记，数据库触发器校验任务所有权；RPC 使用调用者权限，不使用管理员密钥。列表的当前页和总数在一条数据库语句中计算，使用稳定排序；跨页之间仍可能因其他设备修改而变化，可刷新重新核对。

搜索是受账号限制的文字包含匹配，目前未引入全文检索服务。正文会随当前页读取；笔记量很大时需评估索引、列表摘要与详情读取的分离。跨标签页只发送账号范围的随机更新信号，不存笔记内容；不提供跨设备实时订阅、离线写入、历史版本回滚或自动任务生成。

任务完成提示与笔记保存状态独立。原任务完成保存失败时，不把它当作完成成功后邀请写笔记；单独的笔记保存失败不会撤销已经完成的任务。

## 验证

```bash
npm run test:notes
npm run test:todos
npm run test:time
npm run lint
npx tsc --noEmit --incremental false
TOOLKIT_TEST_BROWSER=/opt/google/chrome/chrome npm run test:ui
```

笔记数据库测试使用内存 PostgreSQL，验证关联、删除保留、字数与空白校验、代码缩进、创建重试、版本冲突、搜索分页和 RLS。浏览器测试使用虚假 Supabase 账号与请求，不访问正式数据；真实手机输入法、系统键盘和不稳定网络仍需人工验收。
