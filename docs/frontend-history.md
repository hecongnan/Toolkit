# 前端设计与验证

本次前端重构参考 `emilkowalski/skills` 的 `apple-design` 与 `emil-design-eng`。技能安装在个人 Codex 技能目录，不作为生产依赖提交到项目。后端 API 与 Supabase 数据结构不变，无需再次执行 SQL。

## 设计方向

让个人工作区更专注、清晰和可预测。不是模仿一套系统外观，而是把排版层级、操作反馈、空间关系和无障碍规则落实到组件。

| Before | After | Why |
| --- | --- | --- |
| 深色硬编码和多色渐变 | 中性明暗主题、单一蓝色强调色、语义化状态颜色 | 强调内容，降低视觉噪声 |
| Google 字体构建依赖 | 平台系统字体 | 中文与系统观感一致，减少网络依赖 |
| 主题挂载后写回默认值 | 初次跟随系统，用户选择后记住偏好 | 避免覆盖已保存的选择 |
| 页面尺寸、控件样式分散 | 主题变量与共享基础组件 | 所有页面采用一致的层级与间距 |
| 通用 `transition`、高频操作动效 | 限定属性的短过渡，按压即时反馈 | 不让动画拖慢操作 |
| 非活动导航仍存在于焦点顺序 | 原生模态抽屉 | 非活动导航不可访问，打开时隔离背景 |
| 自制弹窗没有焦点边界 | 原生 `dialog` 加首选字段焦点、Tab 边界、焦点归还 | 键盘与读屏行为明确 |
| 手机操作依赖 hover | 触屏始终可见操作，44px 控件热区 | 不需要猜测隐藏操作的位置 |
| 保存和复制缺少完整反馈 | 保存锁、保留草稿、弹窗内错误、复制成功/失败提示 | 失败后可以继续操作 |

## 组件与规则

- `app/globals.css`：表面、文字、强调色、语义色、阴影、缓动的统一变量。
- `components/shell`：导航、顶栏、内容宽度、标题和跳转到主要内容的入口。
- `components/ui`：按钮、输入框、卡片、标签、空态、加载状态、原生对话框。
- 页面保留现有流程：概览、每日待办、学习资料、项目分析、AI 设置、登录与密码恢复。
- `components/dashboard`：概览各模块独立加载、错误恢复和数据保留；手机先展示待办，桌面使用两栏。
- `components/learning/useMaterials.ts`：资料查询、单项同步锁、状态回滚、实际保存确认；页面负责搜索、排序、详情与编辑流程。
- `components/ui/Notice.tsx`：待办与学习资料共用浮动提示，保留暂停倒计时和可选撤销操作。
- 偶发弹窗使用短的淡入/位移，进入与退出遵循相同空间关系；没有新增拖拽手势或弹簧依赖。频繁列表操作不增加等待动画。
- 键盘打开弹窗不做位移动画；`prefers-reduced-motion` 去掉位移。`prefers-reduced-transparency` 使用不透明材料；`prefers-contrast: more` 加强边界。
- 桌面的次要操作支持悬停/焦点显隐；手机始终显示完成与“更多”入口，次要操作使用文字菜单。放大文字时，内容换行，菜单允许滚动。
- 旧组件中的 `teal` 工具类暂映射到统一蓝色以保持兼容，新组件优先使用语义变量；可以逐页迁移旧工具类，不影响数据层。

## 后续事项

### 移动端待办反馈

完成和恢复任务先更新本地状态，再保存到 Supabase。每项任务独立同步，可以连续勾选不同任务；同一项在保存期间不能重复提交。失败时只恢复该项，保留其他项的成功结果，并显示包含任务名称的错误。保存需返回一条实际更新的记录，避免权限限制或任务已被删除时误报成功。

完成操作不重新读取整个列表；已有后台请求通过请求序号作废，防止旧数据覆盖新状态。新增、编辑、删除和排序后的读取在后台进行，保留现有列表；首次加载、切换日期和加载失败后的重试显示加载状态。成功提示不占列表布局空间，普通提示五秒后消失，含撤销的提示八秒后消失，也可手动关闭。保留即时按压反馈，不添加任务移除等待动画。

同步期间暂时锁定日期和结构修改，避免重复计划的编辑、删除与完成请求相互覆盖；其他任务的完成按钮继续可用。数据库结构与重复计划规则不变，无需执行新的 SQL。

### 撤销完成与移动端操作收纳

使用 `apple-design` 的可恢复操作、触控尺寸和清晰层级原则，以及 `emil-design-eng` 的高频操作即时响应、稳定布局和细节验证原则。不增加动画库或生产依赖。

| Before | After | Why |
| --- | --- | --- |
| 完成后需展开“已完成”寻找任务才能恢复 | 服务端确认后，浮动提示提供带任务名称的“撤销完成”；原有恢复入口保留 | 方便纠正误触，提示消失后仍能恢复 |
| 并发成功反馈由网络返回顺序决定 | 通知只对应最后发起的用户操作，撤销按任务 ID 执行 | 慢请求不能将撤销对象换成另一条任务 |
| 手机每条任务另占一行显示多个图标 | 左侧 44px 完成按钮、右侧 44px 更多按钮，优先级置于内容下方；编辑、跳过、排序、删除移入文字菜单 | 让任务内容成为主要信息，也减少误触 |
| 小屏边缘的菜单可能被卡片裁剪 | 菜单挂载在 body，按可视区域翻转位置并限制尺寸；滚动或改变窗口大小时关闭 | 不超出屏幕，保持与触发任务的关系 |
| 提示倒计时可能在用户阅读或聚焦时结束 | 悬停操作按钮、键盘聚焦或标签页隐藏时暂停；恢复后重新给出阅读时间 | 不让撤销按钮在操作中突然消失 |

撤销沿用单项乐观更新与实际保存确认；失败只恢复该任务，并保留重试入口。菜单支持方向键、Home/End、Tab、Escape、外部点击与焦点归还；删除仍需现有确认对话框，跳过只影响当前重复任务，不改未来规则。频繁操作不新增等待动画。

### 欢迎界面优化

以下改进已经实现，并通过隔离数据的浏览器测试与手机、桌面截图检查。模块加载逻辑与展示组件分开维护，不增加生产依赖。

| Before | After | Why |
| --- | --- | --- |
| 手机概览先显示三张统计卡，待办在其后 | 手机先显示今日待办，统计缩为三张紧凑摘要；桌面两栏 | 首屏直接帮助用户开始行动 |
| 新账号看到多个零值和空状态 | 空账号显示“创建第一条待办”，学习和 AI 设置为可选入口 | 减少首次使用的选择负担；有其他日期任务时不误判新账号 |
| 任一模块查询失败后，整个概览隐藏 | 每个模块独立加载和重试，首次加载使用静态占位，刷新保留现有内容 | 单个故障不影响其他功能，也不使列表突然清空 |
| 任务预览的圆圈像复选框，但不能点击；手机隐藏时间 | 整行是明确的查看入口，时间始终显示，标题可显示两行 | 让外观与行为一致，保留重要信息 |
| 密码始终遮蔽，登录与注册都显示“至少 6 位” | 44px 显示密码按钮，触摸保持输入焦点；登录提示输入密码，注册规则持续显示 | 方便手机核对输入，减少错误 |

浏览器自动化已覆盖 Chromium 的桌面与模拟触屏；仍建议在真实 iPhone/Safari 和 Android 上检查键盘弹出、系统日期选择器与网络较慢的场景。

本次安装的 Playwright 仅用于开发测试，不增加生产页面依赖。依赖审计发现既有 Next.js 14 及其部分依赖存在安全告警；修复建议涉及 Next.js 主版本升级，应单独验证 EdgeOne 的构建、认证与服务端路由兼容性，不能用一次 `npm audit fix --force` 混入视觉重构。

### 学习资料工作流

本轮沿用 `apple-design` 的即时反馈、可恢复操作、清晰层级与触控规则，结合 `emil-design-eng` 对高频动作、稳定布局和异常细节的要求。没有增加动画库、AI 限流、middleware 或数据库迁移。

| Before | After | Why |
| --- | --- | --- |
| 点击状态徽标循环切换，不知道下一步是什么 | 原生选择框直接选择待学、进行中、已完成 | 选择明确，键盘和手机都可用 |
| 状态失败重新加载整个列表；同项可并发写入 | 同项同步期间锁定，其他项仍可操作；失败只恢复对应资料并提供重试 | 防止互相覆盖与整页闪动 |
| 保存后整列表重新读取，没有验证真正更新的行 | 保存/删除返回实际记录后局部更新；新建使用固定草稿 ID 的 upsert | 减少等待、防止误报成功和重试重复创建 |
| 列表按状态自动重新排序 | 默认最近添加，状态更新不触发卡片换位；可主动选择优先级或最近更新 | 不让常用操作移动用户手下的内容 |
| 笔记被截断，查看需要进入编辑 | 继续学习入口、独立只读详情、完整笔记与全部标签 | 接着学习不需要进入编辑流程 |
| 只有关键词与分类，没有结果说明和快速恢复 | 跨标题/标签/分类/笔记/链接组合搜索，显示计数、排序、清除搜索与筛选 | 容易定位资料；没有匹配不等于资料丢失 |
| 只用 URL 输入类型检查链接 | 仅允许 HTTP/HTTPS 且拒绝带凭证链接；旧数据也做展示侧防护 | 避免执行不安全协议或暴露内嵌凭证 |
| 浏览器 confirm 删除资料 | 原生对话框说明笔记会被移除，错误留在框内，成功后回到搜索 | 确认对象清楚，失败不丢资料，焦点不丢失 |

刷新保留现有卡片、详情数据和筛选条件；失败时仍可使用资料。通过请求序号作废旧读取，防止较慢的刷新覆盖新的状态。继续学习根据最近更新的“进行中”资料推荐，不自动变更进度，不追踪外部网站阅读行为。没有进行中资料时给出开始学习入口。

搜索大小写不敏感，并归一化全角字符；分类筛选使用空字符串表示全部，避免名为 `all` 的实际分类冲突。标签支持中英文逗号、顿号和换行，保存前去重；原有更多标签与完整笔记保留在详情中。较窄的手机使用两列筛选按钮，普通手机和桌面为四列；长标题、分类、标签均允许换行，缩略标题可在详情中阅读。

### 学习资料架构：用户友好第一阶段

继续使用 `apple-design` 的清晰层级、操作自主权、输入保护及 44px 触控规则，结合 `emil-design-eng` 的渐进展示、即时反馈与异常状态细节。不增加动画等待、生产依赖或数据库迁移。

| Before | After | Why |
| --- | --- | --- |
| 添加窗口一次展示全部字段 | 标题、链接、笔记优先；分类、标签、状态与优先级放进可即时展开的更多选项，编辑默认展开 | 快速收藏不用先做所有整理决定，原有能力仍可发现 |
| 分类需要重复输入 | 原生输入建议配合可触摸的已有分类按钮，仍可创建新分类 | 复用分类并减少拼写差异，不强制分类体系 |
| 关闭、刷新后未保存输入丢失 | 关闭前提示保留或放弃；当前标签页按账号和资料 ID 保留草稿，刷新后恢复 | 防止误触丢内容，不自动发布草稿 |
| 搜索和排序离开页面就失效 | 标签页保存当前账号的查找状态与滚动位置；URL 可携带筛选，明确链接优先于记忆 | 返回继续找，同一链接的行为可预测 |
| 页面混合表单、草稿、筛选与详情逻辑 | 页面只编排；查询变更、查找记忆、编辑草稿、工具栏和详情各自维护 | 异常恢复和后续功能可独立修改与验证 |

组件职责：

- `useMaterials`：读写资料、逐项同步锁、状态回滚与旧读取作废，同时提供已验证的账号 ID。
- `useLearningView`：URL 参数校验、账号隔离的标签页记忆、返回时的滚动恢复；使用历史替换，不因每次输入制造浏览器后退记录。
- `LearningToolbar`、`ContinueLearning`、`MaterialDetails`：查找、推荐与只读详情展示，沿用原有语义。
- `MaterialEditor`：保存锁、错误提示、关闭保护与清除确认。
- `useMaterialDraft`：字段状态、按账号/资料隔离的 sessionStorage 草稿、刷新提醒、保存后清理。
- `MaterialForm`：受控字段、更多选项、分类建议和提交校验。

草稿仅存在当前浏览器标签页，不跨设备同步，不替代正式保存；关掉标签页后不能保证恢复。存储不可用时明确提示，不提供虚假的“保留草稿并关闭”；仍能保存到数据库。清除编辑草稿只恢复表单原始值，不删除正式资料。创建草稿恢复后继续复用同一个 UUID，避免失败重试产生重复资料。保存中关闭/重复提交被同步锁阻止。

筛选参数为 `q`、`category`、`status`、`sort`；URL 不包含笔记正文或账号 ID。分享 URL 会包含搜索词和分类名称，因此不要在搜索框输入需要保密的内容后分享链接。没有筛选参数时使用当前账号的标签页记忆；明确筛选链接覆盖记忆；未知状态/排序回退到默认值，保留无关 URL 参数。不依赖 Next.js middleware。

本阶段不增加分页、全库查询、最近打开追踪、回收站或多端冲突控制。当前搜索和计数仍覆盖本次加载的资料，继续学习仍根据进行中资料的更新时间推荐。下一阶段必须同步设计分页、全库搜索与统计，不能仅分页而留下局部搜索误导用户。

### 页面切换与任务添加弹窗

沿用 `apple-design` 的即时反馈、清晰字段层级、稳定内容与触控规则，以及 `emil-design-eng` 对高频导航不等待装饰动画、异常状态与键盘交互的要求。

| Before | After | Why |
| --- | --- | --- |
| 路径改变后重新请求账号并用校验画面替换工作区 | 根布局提供共享的已验证账号；导航只判断是否需要跳转 | 侧栏和页面不反复卸载，减少等待 |
| 侧栏、概览和资料模块分别请求账号 | 共同读取 AuthProvider 中的账号信息 | 避免重复网络请求，账号展示保持一致 |
| 后台校验可能覆盖新的登录状态 | 请求序号作废旧结果；退出和账号变更立即隐藏旧内容 | 慢响应不能复活已退出账号或串用资料 |
| 添加表单常驻待办列表上方 | 明确的“添加任务”按钮打开原生弹窗 | 页面更专注任务内容，添加流程独立 |
| 日期跟随列表，时间和重复缺少完整字段说明 | 弹窗集中任务内容、可修改日期、可选时间、优先级和重复规则 | 安排一次完成；时间仅为计划时间，不误称提醒功能 |
| 添加失败在页面顶部提示 | 错误留在弹窗，输入和 UUID 保留；同步锁阻止重复提交和关闭 | 方便原地重试，不重复创建 |

AuthProvider 首次使用服务端 `getUser` 验证，不把本地 cookie 或 `getSession` 当作服务端授权。监听登录、退出、令牌刷新和账号更新事件；回到页面时，距离上次检查至少一分钟才后台验证，同一时刻只有一项检查。恢复网络或用户明确重试也可检查。已验证账号遇到暂时网络错误时保留页面并提供重试；明确的失效响应会隐藏工作区并前往登录。账号身份变化时清空旧页面组件状态，旧校验响应通过序号作废。

共享账号仅存在本次应用运行的内存中，不新增永久登录缓存。API 路由的服务端校验和 Supabase RLS 保留；不重新加入 middleware。认证回调中不 await Supabase 方法，避免与客户端内部锁互相等待。

任务弹窗默认不重复、中优先级、无指定时间，日期默认为列表当前日期；允许在弹窗改为其他日期。工作日重复显示实际起始日期，安排到其他日期时成功提示说明去哪里查看。已有数据库 RPC 及重复计划语义不变，不需要迁移 SQL。

取消或 Escape 只关闭弹窗，不创建任务。未提交内容按账号隔离保存在当前标签页的 sessionStorage，返回待办页面或刷新后可恢复；不跨设备同步，关闭标签页后不能保证恢复。成功后清空输入、重置默认值并归还添加按钮焦点；保存期间保留原任务列表，失败重试继续使用同一个创建 UUID。

隔离测试覆盖导航校验次数与闪屏、首次失败重试、后台失效/网络失败、跨标签页退出与旧响应、登录后返回目标页，以及创建参数、失败重试、取消保留、触屏、小屏大字号与键盘焦点。真实手机的系统时间选择器和键盘仍需实际设备补充检查。

### 任务草稿与创建结果确认

依据 `apple-design` 的操作自主权、输入保护、可恢复操作和明确反馈，以及 `emil-design-eng` 的异常细节、高频动作不等待动画原则，补齐任务弹窗的长期使用细节。本轮不修改数据库，不增加动画库或生产依赖。

| Before | After | Why |
| --- | --- | --- |
| 任务草稿仅存在当前组件，跳转或刷新后丢失 | 账号隔离的标签页草稿，恢复内容、日期、时间、优先级、重复规则和创建 UUID | 减少重复输入，失败重试不重复创建 |
| 只按任务文字判断是否跟随列表日期 | 仅空白草稿跟随当前日期；时间、规则或日期已经修改时保留原安排 | 防止还没输入标题时改好的安排被悄悄重置 |
| 没有主动清除草稿入口 | 明确的清除确认，取消可保留；成功清除后回到内容输入框 | 用户掌控草稿，不误删正式任务 |
| 存储异常与正常保存草稿表现一致 | 提示无法保留，关闭前说明风险；移除失败不伪装清除成功 | 不承诺实际无法实现的恢复能力 |
| 创建只检查 RPC 是否报错 | `.single()` 要求实际返回的任务记录，并验证 ID 等于当前草稿 ID | 空结果和不相关记录不能误报成功 |
| 恢复草稿后，短屏幕需滚到表单末尾才能添加 | 底部取消/添加区使用无动画的 sticky 定位，字段独立滚动 | 不让完成操作藏在长表单下面 |

`useTodoDraft` 负责字段、格式校验、默认日期、按账号隔离的标签页存储、明确清除与保存后重置；表单保留原生弹窗、提交锁、触控尺寸和焦点归还。任务草稿记录有版本号；损坏数据、无效日期/时间/优先级和其他账号的草稿不会进入当前表单。日期输入中的暂时空值可作为草稿保留，但不能提交。

正常关闭不额外要求确认，已有草稿保持可恢复；只有浏览器无法保留草稿时才增加风险提示。弹窗打开且有未提交内容时，刷新/关闭页面会触发浏览器原生提醒（是否展示由浏览器决定）。确认清除和提交不能并发执行；清除失败保留原输入并显示错误。成功保存清理草稿；极端存储清理失败时，恢复后的相同 UUID 仍由数据库的幂等创建逻辑防止重复记录。

创建接口沿用现有 `todo_create` 的 `public.todos` 返回类型，不需执行 SQL。隔离浏览器模拟已同步为返回实际任务对象；SQL 测试继续验证真实函数的权限、重复规则和幂等性。错误在弹窗中保留；明确清除或重新打开时不沿用上一份草稿的错误。

### 任务查找与返回恢复

继续使用 `apple-design` 的即时反馈、范围明确、稳定列表和可触摸控件，以及 `emil-design-eng` 的高频操作不等待动画与异常细节原则。搜索直接筛选已加载数据，不增加请求、动画库或 SQL 迁移。

| Before | After | Why |
| --- | --- | --- |
| 任务多时只能逐条浏览 | 搜索任务内容与计划时间，兼容大小写、全半角、多关键词同时匹配 | 输入即时生效，减少寻找成本 |
| 搜不到与当天没有任务容易混淆 | 单独显示没有匹配的状态、范围和数量；一键清除并回到输入框 | 隐藏不等于删除，避免误解 |
| 完成和跳过分组默认收起 | 搜索时自动展开匹配分组，保留完成、编辑、撤销与恢复 | 不让匹配结果藏在折叠内容中 |
| 过滤列表后仍可能调整局部顺序 | 搜索期间收起拖拽和上/下移；进度使用当日全部任务 | 避免漏看任务后误排序，不让搜索改变进度口径 |
| 返回待办页重新回到今天 | 当前标签页按已验证账号记住日期与搜索条件；今天模式随日期更新 | 接着处理，不重复查找，也不串用账号状态 |
| 概览和侧栏都打开相同的默认入口 | 概览的今日入口明确指定今天并清空搜索；侧栏恢复上次查看 | 保持“今日待办”语义，明确入口优先于记忆 |
| 320px / 200% 字号下图标点击区挤压任务文字 | 移动端纯图标操作保持至少 44px，搜索装饰与清除不随文字放大占满输入框；今天按钮不拆字 | 放大文字仍可阅读、点击和查找，不出现单字竖排 |

`TodoSearch` 负责输入、范围、清除和结果反馈；`todoMatchesQuery` 仅匹配文字与计划时间，不匹配完成状态，完成任务不会因为状态变化而消失；`useTodoView` 负责账号隔离的标签页记忆与入口日期校验。恢复在第一次任务读取之前完成，不先请求今天再切换到记忆日期。损坏存储、无效日期、账号变化和存储不可用不会阻止使用任务页。

搜索仅覆盖当前日期；今天额外包含已经加载的逾期任务。尚未加载的逾期记录需要“加载更多”后才能匹配，界面明确显示已加载范围；其他日期必须切换查看。这不是跨日期或全数据库搜索。当日进度仍排除跳过的任务，并计入搜索隐藏的任务。

查看记忆仅限当前标签页，不跨设备同步，不恢复滚动位置。返回今天模式会采用访问时的今天，明确选择的历史或未来日期则保持不变。支持入口参数 `date=YYYY-MM-DD`、`date=today` 与 `q`；参数进入页面后即消费，保留其他参数和锚点，随后选择可在刷新时恢复。日常输入不写入 URL、不增加后退记录；本轮不提供可分享搜索链接。

验证使用隔离账号和任务样本，覆盖全半角/多关键词/计划时间、结果数量和完整进度、无匹配清除、完成与撤销失败重试、搜索中的排序保护、逾期加载边界、导航/刷新恢复、概览今日入口、账号隔离/损坏存储/无效日期、触控与 320px 大字号布局。自动化浏览器不能替代真实手机的键盘与输入法检查。
